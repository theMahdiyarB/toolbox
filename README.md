# 🧰 جعبه‌ابزار آفلاین

**نسخه ۱۱.۰** · **۱۳۷ ابزار** کاربردی، سبک و آفلاین، با رابط **فارسی و انگلیسی**، قابل نصب روی موبایل و دسکتاپ.

🌐 **پیاده‌سازی‌شده:** [mahdiyar.info](https://mahdiyar.info/)

---

## ✨ ویژگی‌ها

- **آفلاین** - Service Worker تمام فایل‌ها (به‌جز ابزارهای آنلاین) را در اولین بازدید کش می‌کند؛ پس از آن بدون اینترنت کار می‌کند.
- **دو زبانه (فارسی / English)** - دکمهٔ زبان در نوار بالای صفحه (**EN** / **FA**). انتخاب شما ذخیره می‌شود و جهت صفحه (RTL/LTR) پیش از اولین رسم تنظیم می‌شود. بیش از ۸٬۲۰۰ عبارت ترجمه شده و در حالت انگلیسی هیچ متن فارسی‌ای در رابط باقی نمی‌ماند (ارقام و نشانه‌ها هم لاتین می‌شوند).
- **قابل نصب (PWA)** - به صفحه اصلی اندروید/iOS اضافه می‌شود یا به‌عنوان اپ دسکتاپ نصب می‌شود؛ آیکون maskable برای اندروید دارد.
- **به‌روزرسانی سریع** - صفحهٔ اصلی با راهبرد «اول شبکه، بعد کش» بارگذاری می‌شود؛ نسخهٔ جدید از اولین رفرش دیده می‌شود و در حالت آفلاین از کش استفاده می‌شود.
- **اسکن سند (شبیه CamScanner)** - در ابزار PDF، تب «📷 اسکن سند»: عکس سند از گالری یا دوربین، تشخیص خودکار لبه‌ها (Scanic) و برش با کشیدن چهار گوشه، صاف‌کردن پرسپکتیو، فیلترهای اصلی / خودکار / رنگ جادویی (حذف سایه) / خاکستری / سیاه‌وسفید، روشنایی، کنتراست و چرخش، چندصفحه‌ای و خروجی PDF یا تصویر.
- **ذخیره با نام دلخواه** - در ابزار تصویر و ابزار PDF پیش از دانلود می‌توانید نام فایل را تغییر دهید (پسوند ثابت می‌ماند، نویسه‌های غیرمجاز حذف می‌شوند، Enter = دانلود، Esc = انصراف).
- **نقشهٔ مترو با مسیریابی** - تهران، شیراز، اصفهان و مشهد؛ زمان‌بندی قطارها، کمترین تعویض یا سریع‌ترین مسیر، و در هر **تعویض خط** جهت حرکت (ایستگاه پایانی خط جدید، مثلاً «به سمت آزادگان» در ایستگاه مهدیه).
- **ناوبری** - ناوبر کناری (Navigation Rail) روی دسکتاپ و نوار پایین روی موبایل. منوی شناور هر دسته **دقیقاً با ترتیب کارت‌های صفحهٔ اصلی** است و دکمهٔ «خانه» منوی شناور ندارد.
- **Material Design 3** - تم تاریک/روشن، چیدمان منطقی (RTL/LTR)، فونت وزیرمتن، بازخورد لمسی در موبایل.
- **فارسی‌محور** - تقویم خورشیدی (جلالی)، داده‌های ایران (هواشناسی، زلزله، قیمت‌ها، پلاک، کد ملی و ...).
- **حریم خصوصی** - پردازش ابزارهای آفلاین کاملاً در مرورگر انجام می‌شود؛ فایل‌های شما به هیچ سرور ارسال نمی‌شود. فقط ابزارهای آنلاین (هواشناسی، زلزله، ترجمه، قیمت‌ها، رهگیری پست و ...) از طریق پروکسی سرور درخواست می‌فرستند.
- **معماری تک‌فایلی** - تمام اپلیکیشن در یک `index.html` است (به‌همراه `static/`)؛ بدون نیاز به build، npm یا فریمورک.

## 🌍 رابط انگلیسی

- با دکمهٔ **EN** در نوار بالا فعال می‌شود و با **FA** به فارسی برمی‌گردد.
- ترجمه در مرورگر و از روی فرهنگ داخلی (`UI_KEYS`) انجام می‌شود (بدون سرویس بیرونی)؛ نام ایستگاه‌ها، کشورها، شهرها و ایستگاه‌های هواشناسی از دادهٔ خود برنامه گرفته می‌شود.
- پنج ابزارِ ویژهٔ زبان فارسی در حالت انگلیسی پنهان می‌شوند: دیوان شعر، قانون اساسی، فرهنگ واژه پارسی (پاسبان)، تبدیل کیبورد و رفع خرابی متن. برای تغییر فهرست، آرایهٔ `FA` را در اسکریپت کوچک انتهای `index.html` ویرایش کنید.
- دادهٔ خارجیِ فارسی (مثلاً برخی نام مکان‌های IRSC که در فرهنگ نیستند و اشعار گنجور) ترجمه نمی‌شود.

### نکته‌های ابزارهای فایل
- **ابزار تصویر / PDF:** همهٔ خروجی‌ها (ویرایشگر، دستهٔ تصاویر، ZIP، فشرده‌سازی، ادغام، تقسیم، استخراج متن و تصویر) پیش از دانلود پنجرهٔ «ذخیره با نام» را نشان می‌دهند. در بخش‌های مختلف گزینهٔ فشرده‌سازی وجود دارد.
- **ابزارهای مالی و اداری** (فاکتور و رسید، رزومه‌ساز، محاسبه حقوق، ثبت هزینه) خروجی PDF/Word یا چاپ دارند و داده‌ها فقط در مرورگر ذخیره می‌شوند.

```
│   ├── lib/                           ← کتابخانه‌های محلی (بخش وابستگی‌ها)
│   ├── maps/                          ← نقشه‌های رسمی مترو (jpg/pdf)
│   └── poems/                         ← اشعار کلاسیک (ساختار سلسله‌مراتبی)
```

### معماری سمت سرور (Backend)

تمام درخواست‌هایی که از مرورگر به سایت‌های دیگر (CORS) نیاز دارند از یک پروکسی واحد عبور می‌کنند:

- **`scripts/api_proxy.py`** (پورت ۸۰۸۵، پشت Caddy) — مسیرها:
  - `/weather-proxy` و `/weather-static` → هواشناسی (irimo.ir)
  - `/irsc-proxy` → زلزله (فایل `earthquakes.json` از دیسک سرویس می‌شود؛ کرون: `*/15 * * * * python3 scripts/api_proxy.py --fetch-eq`) و منبع تکمیلی EMSC
  - `/post-track` → رهگیری مرسوله (tapin.ir)
  - `/api-proxy` → قیمت و نرخ ارز/طلا/رمزارز و بانک فیلم
  - `/translate-proxy` → ترجمهٔ متن
  - `/img-proxy` → دریافت تصویر با رعایت CORS
  - در Caddy باید برای هر مسیر `reverse_proxy` به `127.0.0.1:8085` تعریف شود؛ پس از هر تغییر `api_proxy.py` سرویس را ری‌استارت کنید.
- **`scripts/bale_bot.py`** — ربات تلگرام/بل.
- **`scripts/ai_service.py`** — سرویس TTS (Piper) / OCR / STT (Whisper).

### تنظیمات مختص استقرار (Deployment-specific)

- **`scripts/api_proxy.py` → `ALLOWED_ORIGINS`**: فهرست مبدأهای مجاز CORS (درخواست‌های هم‌مبدأ همیشه مجازند).
- **`scripts/bale_bot.py` → `TOOLBOX_URL`**: نشانی عمومی جعبه‌ابزار برای WebApp.
- **`manifest.json`**: از نسخهٔ ۱۱ نشانی‌ها نسبی هستند (`id` و `scope` برابر `/` و `start_url` برابر `/?source=pwa`) و نیازی به تغییر دامنه نیست.

## 🚀 راه‌اندازی

### روش ۱ - باز کردن مستقیم فایل
فایل `index.html` را در مرورگر باز کنید. اکثر ابزارها از `file://` کار می‌کنند.

> ⚠️ Service Worker، PDF.js و بخشی از ابزارها به سرور HTTP نیاز دارند.

### روش ۲ - سرور محلی (توصیه‌شده)

```bash
python3 -m http.server 8000      # پایتون
npx serve .                      # Node.js
```

### روش ۳ - استقرار روی GitHub Pages یا سرور اختصاصی (Caddy)

۱. ریپو را بسازید و فایل‌ها را push کنید؛ در **Settings → Pages** شاخهٔ `main` و پوشهٔ root را انتخاب کنید.
۲. برای دامنهٔ اختصاصی رکورد `CNAME` اضافه و **Enforce HTTPS** را فعال کنید. با نشانی‌های نسبی `manifest.json` نیازی به ویرایش دامنه نیست.
۳. روی سرور اختصاصی علاوه بر فایل‌های استاتیک، مسیرهای پروکسی (بخش Backend) را در Caddy تعریف کنید. برای حذف پس‌زمینه سرآیندهای `Cross-Origin-Opener-Policy` و `Cross-Origin-Embedder-Policy` لازم است. برای `sw.js` از `Cache-Control: no-cache` استفاده کنید.

## 🔄 به‌روزرسانی اپ

۱. تغییرات را مستقیماً در `index.html` / `static/` اعمال کنید.
۲. شمارهٔ کش را در `sw.js` افزایش دهید (فعلی: `toolbox-v11.1`) تا فایل‌های قدیمی حذف شوند:

```js
const CACHE_VERSION = 'toolbox-v11.1';   // → 'toolbox-v12.0'
```

۳. اگر فایل جدیدی (مثلاً آیکون یا کتابخانه) برای حالت آفلاین لازم است، آن را به `SHELL_URLS` اضافه کنید.
۴. فایل‌ها را روی سرور بگذارید. صفحهٔ اصلی «اول شبکه» بارگذاری می‌شود، پس کاربران آنلاین نسخهٔ جدید را در اولین رفرش می‌بینند.

اگر بعد از استقرار نسخهٔ قدیمی دیده شد: DevTools → Application → Service Workers → Unregister و Clear site data، سپس Hard Reload.

## 🤝 مشارکت در پروژه

برای افزودن ابزار جدید:

1. ریپو را Fork کنید.
2. پنل ابزار را داخل `<template id="tpl-نام">` یا بلوک ابزارها اضافه کنید.
3. جاوااسکریپت ابزار را اضافه کنید.
4. یک لینک‌کارت در بخش مناسب صفحهٔ اصلی بگذارید. منوی ناوبر و منوی شناور دسته از روی همین کارت‌ها و با همان ترتیب ساخته می‌شوند.
5. نام ابزار را به `TOOL_TITLES` و در صورت نیاز آیتم دسته را به `RAIL_CATS` اضافه کنید.
6. عبارت‌های فارسی جدید را در فرهنگ ترجمه (`window.UI_KEYS` داخل `index.html`) وارد کنید تا در حالت انگلیسی فارسی باقی نماند.
7. برای دانلود فایل در ابزارهای فایل از `TBX.dlAs(blob, name)` (با پنجرهٔ تغییر نام) یا `TBX.dl(blob, name)` (مستقیم) استفاده کنید.
8. یک Pull Request باز کنید.

لطفاً سبک کد را رعایت کنید - JavaScript خالص، بدون فریمورک، سازگار با RTL/LTR، قابل استفاده آفلاین.
